## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a predictive maintenance system, a security flaw can be used to hide real mechanical failures or trigger false alarms to disrupt production. If you discover a vulnerability affecting the **inference logic**, **FFT integrity**, or **alert hijacking**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows suppressing real hardware alerts, spoofing vibration signatures, or causing remote crashes of the detector node.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
